## The one next small improvement

Turn the summary sentence into the task itself. In the `.summary` paragraph, replace `確認依頼 {requests.length}セット。…` with one line per request that carries the link:

`あなたの確認待ち: smegma 新候補の評価 159枚 → [この159枚を確認]　分からない画像は保留で構いません。`

This is a loop over `requests` using the existing `q.unjudged_url`, with no API change. It puts the tag, count and entry point on the first screen at both widths (the summary sits at about y=640 at 390). Don't add an "完了すると…" clause until the pipeline's actual next step is confirmed, and keep the predicted-positive/negative split out of it.
