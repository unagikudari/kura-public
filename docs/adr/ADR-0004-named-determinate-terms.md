# ADR-0004 — すでに有名で確定的なタグは分解しない

- 状態: 採用 (2026-07-31)
- 決めた人: user (plan kura-1.0-implementation の注釈作業中)
- 関連: ADR-0003 (部位の正規化)、migration 0054 / 0071 / 0074 / 0075 / 0076

## user の言葉

> すでに有名で確定的なタグなら分解する必要はないんだ。
> **それを入れたうえで表現しきれないところを関係で書けばいい**

> 正座とかもそうだろ。腰膝をたたんでつま先を伸ばして脛から膝が地面に接している
> というのを両足に対して書くのか？

> フルネルソンもそうだろ。あれは全身ポーズ関係 p1 フルネルソン p2 で表現できる。
> **そういう関係を内包したセットなんだから**

## 何が問題だったか

この ontology は「flat tag は部位・主体・左右を語の中に埋めてしまう」という観察から
始まっており、`piercing` を部位ごとに作らない (0045)、`punch`/`kick` を作らない (0054)
のように**分解する方向**へ倒してきた。

その勢いで、**名前がすでに中身を決めている形まで分解した**:

- 0071 羽交い締め → `behind` + `restraining (arm → axilla)` × 2 の 3 本
- 0073 両腕で脚を抱える → `holding (arm → thigh)` × 2

結果、注釈者は「ポーズを探しているのに無い」「自分の体だけで完結するのに関係が要る」
という状態に置かれた。**分解は記録の形の話で、語彙の単位の話ではなかった。**

## 決定

**すでに有名で確定的なタグは、そのまま 1 語として持つ。**
そのうえで、**その語が言えないところだけを**部位・属性・関係で補う。

判定は 1 つ: **名前が部品を決めているか。**

| | 例 | 扱い |
|---|---|---|
| 名前が部品を決めている | 正座 / 羽交い締め / 両腕で脚を抱える / 対面座位 | **1 語**。条件は語の説明に書く |
| 部品が画像ごとに変わる | 殴る・蹴る (どこで打つか) / ピアス (どこに) / 手を当てる (どちらの手) | **語 + 部位** に分解 |

`striking` を作って `punch`/`kick` を作らなかった 0054 と矛盾しない。あちらは
**打つ部位が画像ごとに変わる**ので、語を分けると部位の数だけ語が増える。
羽交い締めは後ろから・両腕・腋の下が固定で、変わるものが無い。

## 帰結

1. **内包しているものを別に書かせない。** `full_nelson` は「後ろにいる」を含むので
   `behind` を重ねない (二重の真実)。何を内包しているかは語の説明に書き、後から導く。
2. **一般形は消さない。** 形が決まっていない拘束は `restraining`、片手の接触は
   `touching (hand → region)`。名前のある形はその**特殊形**として並ぶ。
3. **語が言えないところは関係で足す。** 「羽交い締めにしつつ、右手で口を塞いでいる」は
   `full_nelson` + `covering (hand → mouth)`。**1 語で終わらせない**のがこの ontology の
   利点で、それは 1 語を持つことと両立する。
4. **flat tag との対応が素直になる。** `phrase_macro.tag_name` (0072) は
   「その tag を primitive で言うと何か」の表だったが、確定的な語については
   **1 対 1 の対応**になる。取りこぼしの測定 (0072) はそのまま使える。
